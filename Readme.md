
# ChemLab

Скачайте проект и разархивируйте его.

Откройте консоль в папке с проектом и создайте виртуальное окружение: 
```bash
python -m venv venv
```

Активируейте виртуальное окружене используя команду:
```bash
venv\Bin\activate
```

Для того, чтобы запустить проект используйте:
```bash
python manage.py runserver
```
или
```bash
python3 manage.py runserver
```

Сайт запустится по следующему url адресу:
```bash
http://127.0.0.1:8000/
```

Чтобы перейти в панель-администратора добавьте в URL-адрес "/admin".

Получится:
```bash
http://127.0.0.1:8000/admin
```

Данные для входа:
```bash
Имя пользователя: user
Пароль: 123345678
```
